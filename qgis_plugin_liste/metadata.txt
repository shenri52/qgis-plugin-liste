about=Standalone QGIS plugin to export the installed plugins list as HTML or CSV. It uses plugin-provided localized descriptions when available and otherwise attempts automatic translation. HTML pages are generated from editable template files (four are provided, you can import your own or edit them in the built-in editor), and you choose which fields are exported. The export dialog is available from the Extensions menu and the toolbar.
about[fr]=Extension QGIS autonome permettant d’exporter la liste des extensions installées en HTML ou CSV. Elle utilise les descriptions traduites fournies par les extensions et, à défaut, tente une traduction automatique. Les pages HTML sont générées à partir de modèles modifiables (quatre sont fournis, vous pouvez importer le vôtre ou les modifier dans l'éditeur intégré), et vous choisissez les champs exportés. La fenêtre d’export est accessible depuis le menu Extensions et la barre d’outils.
